# The Kitsu Stickers

Source artwork for **[The Kitsu Stickers](https://t.me/addstickers/TheKitsuStickers)** — a Telegram sticker pack starring *Kitsu*, an anime-style cat girl with a lot of opinions and even more hair.

This repository holds every sticker in the pack as WebP, in two sizes: a **512px render** (used for the previews below) and a **full-resolution master**.
